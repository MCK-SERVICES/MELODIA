# Scanix — scanner de documents Android personnel

Gratuit, sans compte, sans pub, sans filigrane. Tout reste sur le téléphone.

## Fonctions
- **Scanner** : détection automatique des bords, redressement de la perspective, filtres
  (couleur, niveaux de gris, noir & blanc amélioré), nettoyage des taches/doigts, plusieurs pages d'affilée
  (scanner Google ML Kit, gratuit et hors ligne)
- **Importer** des photos de la galerie
- Documents multi-pages : ajouter des pages, réordonner, pivoter, supprimer, zoomer
- **PDF** : partage (WhatsApp, e-mail…) ou enregistrement dans *Téléchargements/Scanix*
- **Texte (OCR)** : extraction du texte d'une page ou d'un document entier, copier/partager — hors ligne
- Recherche, renommage, suppression

## Compilation
Automatique sur GitHub Actions à chaque envoi : l'APK est publié dans **Releases**.

Kotlin · Jetpack Compose · ML Kit Document Scanner · ML Kit Text Recognition · Android 8.0 minimum
